Questions

Is it free?

Flitty is free and open source. It uses your own OpenAI API key, so you pay OpenAI directly for what you use, usually a fraction of a cent per question.

What does it send, and when?

Only when you use the hotkey: the recording of your question and a screenshot of your displays, sent directly to OpenAI. Flitty has no server and saves no recordings or screenshots. Your key is stored in Windows Credential Manager.

Does it work on Mac?

Windows comes first. A macOS version is on the way.

Windows says "Windows protected your PC"

The installer isn't code-signed yet. Click More info, then Run anyway. You can check the source and build it yourself from GitHub.

How do I get an OpenAI key?

Create one at platform.openai.com/api-keys, then paste it into Flitty's Settings (click the tray icon) and press Test key.
